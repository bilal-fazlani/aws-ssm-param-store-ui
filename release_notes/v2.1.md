# v2.1

A quality-of-life update introducing an inspector panel for parameter metadata, a faster way to add parameters directly from the sidebar, and smarter delete confirmations.

## What's New

**Inspector Panel**
- A new inspector panel slides open alongside the detail view for any selected parameter
- Three tabs — Info, History, and Tags — show metadata, version history, and AWS tags
- Toggle the inspector from the toolbar or via a keyboard shortcut

**Sidebar Add Button**
- Hover over any folder in the sidebar to reveal a "+" button that opens the Add sheet pre-filled with that folder's path
- A footer button in the sidebar also lets you add a new parameter at the root level
- Press Escape from any field in the Add sheet to dismiss it immediately

**Smarter Delete Confirmations**
- When deleting a folder, the confirmation alert now lists up to five of the parameter paths that will actually be removed, with an overflow count if there are more
- Makes it easy to verify you're deleting the right things before confirming

**Search Improvements**
- Parameters at hybrid paths (paths that are both a folder and a parameter) are now included in search results
- Hybrid nodes display a combined row that makes their dual nature clear

**Dark Mode Icon**
- The app icon now uses a dedicated fill for dark mode

**Bug Fixes**
- Adding or deleting a parameter at a hybrid path no longer corrupts the tree structure
- Selection is preserved on a hybrid path after its value is deleted
- The Add sheet's duplicate-path check correctly allows adding a value at an existing folder path
